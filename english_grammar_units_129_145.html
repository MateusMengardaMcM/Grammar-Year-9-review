English Grammar Review & Test

Units 129–145 · Prepositions and phrasal verbs

Quick review

Use this page to revise the main patterns before taking the test.

1. Noun + preposition

  • reason for, cause of
  • advantage of, increase in
  • solution to, answer to
  • relationship with, difference between
  • damage to, invitation to

2. Adjective + preposition

  • afraid / proud / aware of
  • good / bad at
  • interested in, keen on
  • similar to, different from
  • married to, responsible for
  • angry with someone / about something

3. Verb + preposition

  • listen / speak / talk to
  • look / stare / point at
  • wait / search / apply for
  • look for = search; look after = take care of
  • depend / rely / concentrate on
  • succeed / believe in
  • apologise to someone for something

4. Important differences

  • hear about = get information; hear of = know it exists; hear from = receive a message
  • think about = consider; think of = have an idea/opinion
  • care about = feel concern; care for = look after / like
  • shout at = angrily; shout to = so someone can hear
  • discuss something (no preposition)

5. Phrasal verbs: in / out

  • get in / get out = enter / leave
  • fill in / fill out = complete a form
  • eat out = eat at a restaurant
  • find out = discover
  • work out = solve / exercise
  • run out of = have none left
  • look out = be careful

6. Phrasal verbs: on / off

  • turn on / off = start / stop a device
  • put on / take off = dress / remove clothing
  • call off = cancel; put off = postpone
  • go on / carry on = continue
  • take off = (plane) leave the ground
  • set off = start a journey

7. Phrasal verbs: up / down

  • give up = quit; grow up = become an adult
  • bring up = mention / raise a child
  • make up = invent; cheer up = become happier
  • turn down = refuse / reduce volume
  • write down = record; let down = disappoint
  • break down = stop working
  • set up = arrange / establish

8. Phrasal verbs: away / back

  • go away = leave; come back = return
  • give back = return something
  • throw away = discard
  • put away = store
  • call back = return a phone call
  • get away with = escape punishment
  • look back = remember the past
Word order rule: With many separable phrasal verbs, a noun can go before or after the particle: turn on the light / turn the light on. A pronoun goes in the middle: turn it on (not turn on it).
Remember: Some combinations are fixed, so learn the whole expression (for example, depend on, afraid of, listen to).
